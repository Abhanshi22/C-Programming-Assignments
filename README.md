# FOP Assignments

This repository contains C programming assignment programs completed for the Foundations of Programming (FOP) course (Semester 2) at MIT World Peace University.

These programs focus on building core programming concepts including:
- Logic building
- Conditional statements
- Loops
- Functions
- Arrays
- Structured programming
